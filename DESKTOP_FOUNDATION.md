# Triada Network Desktop Foundation v1.3.0

This release contains the Windows desktop shell, lifecycle manager, single-instance guard, dynamic loopback port, optional tray, durable logs, clean PyInstaller target, and Inno Setup installer template.

## v1.4 Desktop Runtime

The native shell now includes: dynamic loopback port, single-instance guard, local API supervisor/recovery, system tray controls, diagnostics, encrypted local secret storage, verified backups, optional cloud readiness sync, and update package hash verification.

Desktop data lives under `%LOCALAPPDATA%\Triada Network\`; source code remains under the installed application directory.
